# GitHub Account Switcher for Windows

A lightweight PowerShell script to manage multiple GitHub accounts on Windows by switching SSH keys.

---

## Quick Start

### Step 1: Clone This Repository

```powershell
git clone https://github.com/raqueeb/github-switcher.git
cd github-switcher
```

### Step 2: Generate SSH Keys

```powershell
# Generate for aiwithr account
ssh-keygen -t ed25519 -C "user1@gmail.com"
# Save as: id_ed25519_aiwithr

# Generate for raqueeb account
ssh-keygen -t ed25519 -C "user2@gmail.com"
# Save as: id_ed25519_raqueeb
```

### Step 3: Add Keys to GitHub

```powershell
# View your public keys
cat ~/.ssh/id_ed25519_aiwithr.pub
cat ~/.ssh/id_ed25519_raqueeb.pub
```

1. Go to github.com/settings/keys
2. Click "New SSH key"
3. Add both public keys to their respective accounts

### Step 4: Initialize

```powershell
.\switch.ps1 a   # Start with aiwithr
```

### Step 5: Verify

```powershell
ssh -T git@github.com
# Expected: Hi aiwithr! You've successfully authenticated...
```

## How It Works

The script modifies your SSH config file at:

```
C:\Users\YourName\.ssh\config
```

### Generated SSH Config (aiwithr active)

```config
# GitHub SSH Config - Generated by switch.ps1
# Active Account: aiwithr

Host github.com
    HostName github.com
    User git
    IdentityFile C:\Users\YourName\.ssh\id_ed25519_aiwithr

Host raqueeb.github.com
    HostName github.com
    User git
    IdentityFile C:\Users\YourName\.ssh\id_ed25519_raqueeb
```

### Generated SSH Config (raqueeb active)

```config
# GitHub SSH Config - Generated by switch.ps1
# Active Account: raqueeb

Host github.com
    HostName github.com
    User git
    IdentityFile C:\Users\YourName\.ssh\id_ed25519_raqueeb

Host aiwithr.github.com
    HostName github.com
    User git
    IdentityFile C:\Users\YourName\.ssh\id_ed25519_aiwithr
```

## SSH Key File Locations

After generating keys, your files are stored at:

| File | Path | Purpose |
|------|------|---------|
| Private Key (aiwithr) | `C:\Users\YourName\.ssh\id_ed25519_aiwithr` | Never share this |
| Public Key (aiwithr) | `C:\Users\YourName\.ssh\id_ed25519_aiwithr.pub` | Add to GitHub (aiwithr) |
| Private Key (raqueeb) | `C:\Users\YourName\.ssh\id_ed25519_raqueeb` | Never share this |
| Public Key (raqueeb) | `C:\Users\YourName\.ssh\id_ed25519_raqueeb.pub` | Add to GitHub (raqueeb) |
| SSH Config | `C:\Users\YourName\.ssh\config` | Created by switch.ps1 |

## Cloning Repositories

### Method 1: Using Default (Active Account)

```powershell
# Uses whichever account is currently active
git clone git@github.com:raqueeb/fb_medium_all.git
git clone git@github.com:aiwithr/fb_medium.git
```

### Method 2: Forcing Specific Account

```powershell
# Force aiwithr account
git clone git@aiwithr.github.com:aiwithr/fb_medium.git

# Force raqueeb account
git clone git@raqueeb.github.com:raqueeb/fb_medium_all.git
```

## Switching Accounts for Specific Repos

### Scenario: Clone repo as different account

```powershell
# You're on aiwithr (a), but want to clone raqueeb's repo
git clone git@raqueeb.github.com:raqueeb/some-repo.git
# This uses raqueeb's key even though you're on aiwithr
```

### Scenario: Work on repo under different account

```powershell
# Clone using specific account
git clone git@aiwithr.github.com:aiwithr/project.git

# Later, switch to that account for commits
.\switch.ps1 a

# Now git push will use aiwithr
```

## Security Notes

- **Never share private keys** (files without `.pub` extension)
- **Keep `.ssh` folder private** - Only you should have access
- **Public keys are safe** - Can be shared freely
- **Backup your keys** - Store a copy in a secure location

### Protected Private Key Example

```
# Permissions should be:
# -a----  (read/write for owner only)

# NOT:
# -a--r--  (readable by others) - insecure!
```

## Complete Setup on New PC

### 1. Install Git

Download from: https://git-scm.com/download/win

### 2. Clone This Repository

```powershell
git clone https://github.com/raqueeb/github-switcher.git
cd github-switcher
```

### 3. Generate SSH Keys

```powershell
ssh-keygen -t ed25519 -C "user1@gmail.com"
# Press Enter to save as: id_ed25519_aiwithr
# Enter passphrase (optional, press Enter to skip)

ssh-keygen -t ed25519 -C "user2@gmail.com"
# Save as: id_ed25519_raqueeb
```

### 4. View and Copy Public Keys

```powershell
cat ~/.ssh/id_ed25519_aiwithr.pub
# Copy this output

cat ~/.ssh/id_ed25519_raqueeb.pub
# Copy this output
```

### 5. Add Keys to GitHub

**For aiwithr account:**
1. Go to github.com (logged in as aiwithr)
2. Settings > SSH and GPG keys > New SSH key
3. Paste the aiwithr public key
4. Save

**For raqueeb account:**
1. Go to github.com (logged in as raqueeb)
2. Settings > SSH and GPG keys > New SSH key
3. Paste the raqueeb public key
4. Save

### 6. Initialize Switcher

```powershell
.\switch.ps1 a
```

### 7. Verify Setup

```powershell
ssh -T git@github.com
# Should see: Hi aiwithr! You've successfully authenticated...
```

## FAQ

**Q: Do I need to restart after switching?**
A: No. The change takes effect immediately for new git operations.

**Q: Can I use both accounts simultaneously?**
A: Yes. Use the `aiwithr.github.com` or `raqueeb.github.com` hosts to force specific accounts.

**Q: What if I forget which account is active?**
A: Run `.\switch.ps1` without arguments to see current status.

**Q: Can I use this on Mac/Linux?**
A: This script is Windows PowerShell only. For Mac/Linux, you need to modify the SSH config path and commands.

**Q: Does this work with HTTPS instead of SSH?**
A: No. This script only manages SSH keys. HTTPS authentication is separate.
